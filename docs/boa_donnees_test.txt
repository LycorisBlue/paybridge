 Champs concernes : custom_rib (RIB), custom_bank_code (Code banque),

-------------------------------------------------------------------------------
 RAPPEL DES FORMATS ET REGLES DE VALIDATION
-------------------------------------------------------------------------------
- RIB (custom_rib) : 24 caracteres
    = code banque (5) + code guichet (5) + n. de compte (12) + cle (2)
    Normalise (espaces retires, MAJUSCULES).
    BLOQUE si non-alphanumerique ; AVERTIT (non bloquant) si longueur != 24.

- Code banque (custom_bank_code) : 5 caracteres.
    BLOQUE si non-alphanumerique ; AVERTIT si longueur != 5.
    Si VIDE -> derive automatiquement de custom_rib[:5].
    A ne saisir que si le code banque differe des 5 premiers car. du RIB.

- SWIFT / BIC (custom_swift_code) : pas de validation de format.
    BIC valide = 8 car. (AAAACCLL) ou 11 (AAAACCLLXXX)
    = 4 banque + 2 pays + 2 localite [+ 3 agence].
